# Azure Cloud Security Monitoring System

## Overview

This project demonstrates how to build a cloud security monitoring solution in Microsoft Azure using native monitoring and governance services.

The solution monitors administrative changes to Azure resources by leveraging Activity Logs, Resource Tags, Alert Rules, and Action Groups.

## Technologies Used

- Microsoft Azure
- Azure Monitor
- Azure Activity Logs
- Azure Storage Accounts
- Azure Resource Tags
- Azure Alert Rules
- Azure Action Groups

## Project Objectives

- Detect administrative changes to Azure resources
- Monitor tag modifications
- Improve visibility into resource activity
- Support governance and compliance efforts
- Gain hands-on Azure security monitoring experience
